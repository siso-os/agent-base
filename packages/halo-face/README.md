`WorkspaceMark` is an optional exported React component for the approved Agent Base, SISO Agency and HALO logos. Its `brand` is `agent-base`, `siso-agency` or `halo`; `look` is `prism` (default glass badge), `orbit` or `relief`. It accepts `size`, `paused`, `interactive`, a numeric `replay` trigger and `className`. Example: `<WorkspaceMark brand="agent-base" look="prism" size={48} />`. The source paths are exact extracts from the approved SVGs; `MARKS-SOURCE.json` records their hashes. The originals are retained beside the material studies in the gallery.

Logo portraits have a restrained float, a moving light sweep, an optional pointer tilt and a 1.3-second replay gesture. The orbit adds a travelling light. At 48 px and below, loops are still. Intersection and page visibility pause the animation; reduced motion removes it. Pause/reduce/offscreen changes cancel an active gesture, and resuming does not replay the old trigger. The logo component is available for product integration; existing workspace navigation has not been switched to it.

`AgentFace.tsx` is the actual exported React component. All existing props remain: name, project, hue, status, size, track, interactive, className and title. Project colour uses the unchanged projectHue algorithm. Name identity is normalised and deterministic; it is independent of project and status, but finite feature combinations can collide. Optional family, direction, features, secondHue and paused props support review and explicit customisation. `faceFor` uses Claude/Codex tool metadata when supplied. Views without provider metadata use a deterministic name style; provider attribution for every existing owner-only snapshot has not been audited.

Working focuses its gaze; waiting looks around; needs-shaan is amber; blocked is still and red; done celebrates for 1.55 seconds then settles; offline has closed lids. Navigation faces keep the head stationary and use restrained eyes and a small completion nod. A shared frame scheduler stops when no visible face needs motion. Native reduced motion, document visibility, offscreen suspension and unmount cleanup are handled in the engine. State changes discard the old gesture immediately.
