# Agent Base standalone source cut

The 118 promoted sources are materialized back into their product paths from
the committed adoption receipt and shared provenance. The voice cn import is
reversed to the byte-identical product helper. The typed icons index retains
the verified runtime mapping. This cut uses Agent Base's existing MIT licence;
it does not distribute or relicense the UNLICENSED shared kit. Preserve LICENSE,
THIRD_PARTY_NOTICES.md and packages/siso-icons/LICENSE-pqoqubbw. The root lock is
reduced to exact reachable product records and product overrides only.

Requires Node 22+, pnpm 9.12.0. Install with pnpm install --frozen-lockfile,
then pnpm --filter @agent-base/web exec tsc --noEmit and pnpm build.
Desktop packaging, host services and live acceptance are separate checks.
